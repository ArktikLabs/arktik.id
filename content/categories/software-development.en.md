## Who this is for

The writing in this category is for owners and managers weighing whether to have software built: a web or mobile app, an internal system, a customer portal or a booking system. You don't need to read code to follow it.

The questions we answer are the ones that usually come up before a contract is signed:

- **Build or buy?** When custom software makes sense, and when an off-the-shelf app is enough.
- **Where to start?** How to pick a small first version so the budget isn't spent on features nobody needs yet.
- **How does the work actually run?** What happens at each stage, and what you should get to see every week.
- **What is fair to expect from a software house?** Price, ownership of the code and accounts, and what happens if the engagement ends.

Start with the complete guide if you are still weighing it up, or go straight to the article closest to your question.
